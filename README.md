# Abdul Wasay Ali — Developer Portfolio

A modern, high-performance personal portfolio web application built with **React 19**, **Vite 8**, and vanilla **CSS Modules**. Designed with sleek cyber/glassmorphic aesthetics, smooth micro-interactions, responsive layouts, and centralized data architecture.

## ✨ Features & Highlights

- **⚡ Blazing Fast Build & HMR:** Powered by Vite 8 and React 19 for instantaneous hot module replacement.
- **🎨 Glassmorphic & Modern Dark UI:** Custom styling with CSS custom properties, neon glow gradients, and responsive glass cards.
- **📱 Responsive Mobile Apps Showcase:** Dedicated showcase for Flutter & Mobile applications with aspect-ratio preservation and clean containment.
- **📄 Live Resume Preview & Download:** In-browser modal PDF previewer with direct one-click download support.
- **💬 Direct Multi-Channel Contact:**
  - Integrated contact form with automated email dispatch via FormSubmit.
  - Floating direct WhatsApp quick-chat action button (`+92 3110214934`).
- **🎯 Dynamic Typing Animation:** Custom zero-dependency typing hook cycling through engineering specialties.
- **🧭 Centralized Data Model:** All project items, skills, education, and social links are managed via a single config (`src/data/portfolioData.js`).
- **🌓 Theme Support:** Built-in context provider for seamless dark/light theme switching.

## 🚀 Getting Started (Local Development)

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AbdulWasayAli/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
